# Agent guide

## Tracking work

Work here is tracked in GitHub issues and the **TimeTug** org project, not in progress documents. Follow the [`tracking-work-in-issues`](https://github.com/binary-companion/timetug/blob/master/.agents/skills/tracking-work-in-issues/SKILL.md) skill (in `binary-companion/timetug`): where an issue goes, what it contains, status and the Agent field, sub-issues and blockers, and owner steps as Manual Tasks in the private `binary-companion/manual-configuration` repository. Each issue must be readable on its own, and a pull request closes its issue with `Fixes #N`.
